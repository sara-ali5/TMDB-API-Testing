# TMDB API Testing Project

## Overview
This project contains API test cases for The Movie Database (TMDB) API using Postman.

## Tools Used
- Postman
- JavaScript (Postman Tests)
- TMDB API

## Covered Scenarios
- Authentication (Bearer Token + API Key)
- Movie Search API
- TV Search API
- Movie Details API
- TV Details API
- Credits API
- Popular Movies (Pagination + Sorting)
- Genres API
- Discover API (Filtering)
- Now Playing API
- Watchlist (POST API)

## Validations
- Status codes
- Schema validation
- Business logic validation
- Pagination validation
- Filtering validation
- Idempotency checks

## How to Run
1. Import collection into Postman
2. Import environment file
3. Select environment
4. Run requests manually or via Collection Runner
